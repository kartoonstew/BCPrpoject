# Fighter references in character PDFs

The sheet uses the 2024 Fighter progression, verified against **SRD 5.2.1, pages 47–48**, matching the supplied Fighter Character Sheet 5.5 reference. The Black Company campaign overrides normal character creation and subclass progression: campaign subclasses unlock at levels 1, 3, 7 and 10. No generic subclass, level 15 or level 18 subclass features are invented.

The generator includes only unlocked Fighter descriptions. Extra Attack is shown once, with its current attack count. Ability Score Improvement lists only milestones already reached. Fighting Style, mastery selections and feat choices remain editable player choices. Resource maxima, attacks per Attack action, mastery count and Second Wind's healing expression scale with level. Remaining uses stay manual. Explicit equipment settings calculate equipment totals and the first set of conditional effects; see [equipment rules](equipment-rules.md). Exporting never rests the character or refills an entered counter.

Feature descriptions and which resource trackers exist are snapshots of the character at export. Re-export after a level change to update them. Existing calculated fields can also recalculate in a JavaScript-capable PDF reader. Preview and LibreOffice use the values saved at export. PDF edits do not synchronize back to the website.

The three structured weapon rows accept manual final bonuses, damage and mastery notes. Existing slash-separated loadouts can seed those rows; the complete original loadout is retained in Equipment & notes. Long text continues onto additional editable pages. Bookmarks address every page.
